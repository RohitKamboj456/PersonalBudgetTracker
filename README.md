# PersonalBudgetTracker
Personal Budget Tracker 💰 A simple and intuitive web-based tool to help users manage their monthly income and expenses. Built with HTML, CSS, and JavaScript, this project is designed to provide a clear overview of your finances by categorizing and summarizing transactions.
Features ✨
Add Income/Expenses: Input your income and expenses with ease.

Categorize Transactions: Organize transactions into categories like Food, Transportation, Entertainment, etc.

Budget Summary Table: View a detailed summary of all transactions, including category, amount, date, and type (Income or Expense).

User-Friendly Interface: Clean and responsive design for a seamless experience.
